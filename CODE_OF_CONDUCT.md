# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and keep discussion about
the work. Harassment, insults and personal attacks are not accepted.

To report a problem, use GitHub's private reporting
([Security → Report a vulnerability](https://github.com/CODER7657/kisan_mitra/security/advisories/new),
which reaches the maintainer privately) or contact
[@CODER7657](https://github.com/CODER7657). Reports are handled confidentially.
